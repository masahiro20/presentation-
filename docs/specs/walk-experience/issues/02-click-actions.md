# 02 クリックで動くアクション（ドアを開ける など）

Status: done（戸・シャッター・床クリック。窓・照明・カーテンは見送り／未着手）

## 要望
ドアを開けるなど、クリックしたら動くモーションがあるとリアル。

## できあがり（確かめ方）
- 歩いているときに開き戸・引戸・玄関ドアをクリックすると、動きつきで開閉し、開いた戸口を通れる。
- 候補（着手時に、効果の大きい順に決める）: 窓の開閉、ガレージのシャッター（クリックで巻き上げは済み。歩くモードからも）、照明の入切、カーテン・ロールスクリーン、収納の扉。
- クリックできる物は、カーソルを合わせると分かる（押せると気づける）。
- 体験リンクでお客様が触っても壊れない（元に戻せる）。

## Comments
- 2026-11-17 実装:
  - 戸（開き戸・引戸・玄関）とシャッターは、歩いているときもクリックで開閉（従来から）。カーソルを合わせると手の形になり、「クリックで戸を開ける／閉める」の札が出る（`onWalkHover`）。
  - 床をクリック（タップ）すると、そこまで歩いていく（`walkToClick`。家具の上・壁・15m 超・別の階の高さは動かない。壁ぎわは 0.4m 手前）。キーに慣れていない人向け。
  - 歩き始めに 5 秒だけ「床を押すとそこへ歩きます ／ 戸は押すと開きます」と出す。
  - 元に戻る: 目線モードを抜けると、自動で開けた戸は閉じ直す（従来どおり）。
  - 見送り（理由）: 窓の開閉 — 御社の窓は FIX＋すべり出しが基本で、開けても通り抜けられない。照明の入切・カーテン・収納の扉は未着手（あとでやる候補）。
