# 03 通常目線と「引きの広角目線」の切り替え

Status: done（2026-11-17）

## 要望
人が立って見ているときは、画面の画角で切り取るより、もう少し広く見えているはず。通常の目線と、少し引いた広角の目線を切り替えられる仕組みがほしい。

## できあがり（確かめ方）
- ボタン 1 つ（とキー）で「通常」と「広角」を切り替えられる。歩いている途中でも切り替わる。
- 広角でも、壁・柱・家具が極端に歪んで見えない画角にする（着手時に、同じ場所で数通り撮って決める）。
- 狭い部屋（洗面・トイレ・廊下）で、広角にすると部屋の全体が分かる。

## Comments
- 2026-11-17 実装: 「広角」ボタン（キーは V）。通常 62° ⇄ 広角 84°（縦の画角）。約 0.25 秒でなめらかに切り替わり、歩いている途中でも効く。
  90° も試したが、手前の家具が引き伸ばされて見えたので 84° にした（吉田様邸 LDK で見比べ）。目線モードを抜けると元の画角へ戻る。地図の扇も画角に合わせて広がる。
