# 02 内観を御社のテイストへ（パターンを作る）

Status: needs-triage（何が「らしくない」のかを、御社の実例と見比べて決める所から）

## 要望
内観が「パースを作った感」があり、ホームランディックらしくない。御社のテイストに寄る内観のパターンがほしい。

## 進め方（案）
- 御社の施工例・提案パース（内観）を 5〜10 枚、物差しとして決める（これまでの物差し: 林様・堀様・吉田様の Twinmotion の静止画）。
- 同じ構図で今のパースと並べ、違いを書き出す（素材の質感・色数・照明の当て方・家具と小物・窓の外・カメラの高さと画角）。
- 御社の内観の型を 3〜4 つのパターンにして、1 回で切り替えられるようにする（今の「内観のテイスト」を、御社の実例に合わせて作り直す）。
- 確かめ: 物差しの画像と並べて、御社に「らしい」と言ってもらえること。
