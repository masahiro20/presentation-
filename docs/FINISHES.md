# コーディネートの選択肢（一覧）

ツールの「コーディネート」に入っている商品の一覧です（`src/coordinate/catalog.ts` から `npx tsx scripts/finishes-doc.ts` で作成）。
「御社の採用例」は、過去のお客様の床仕様書・内部仕上表・立面図で実際に使った所です（お客様名は載せていません）。
色名・品番がメーカーの資料で確かめられない商品は「※品番は品番メモに」として、打ち合わせで正確な品番を入れます。
