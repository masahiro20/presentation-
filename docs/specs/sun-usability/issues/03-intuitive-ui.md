# 03 感覚的に使える操作・画面

Status: ready-for-agent

## 要望
日照の画面に使いづらさがある。もっと感覚的に操作できる画面・操作性にする。

## できあがり（確かめ方）
- 着手時に、初めて使う人の順番（場所を入れる → 周辺が立つ → 時刻・季節を動かす → 結果を見る）で実際に操作し、迷った所・クリックの多い所を書き出す。
- 直す所を、効果の大きい順に決めて直す（例: 画面を直接つかんで動かす、時刻・季節はスライダーを動かすとすぐ変わる、よく使う操作を前に出す）。
- 直す前と後で、同じ作業のクリック数と掛かる時間を比べる。
