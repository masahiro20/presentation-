# 04 現在地の地図（右下の平面図。クリックでその場所へ）

Status: ready-for-agent

## 要望
歩いて室内に入ると見づらく、どこにいるか分かりづらい。右下などに平面図を出して、クリックしたらそこへ移動し、その目線で見られるようにする。

## できあがり（確かめ方）
- 歩いている間、画面の隅（右下）に小さな平面図が出て、現在地と向いている方向が分かる。
- 平面図の部屋・場所をクリックすると、そこへ移動して、その目線になる。屋外（庭・道路側）もクリックで出られる。
- 2 階建て以上は、いまいる階の図に切り替わる（階を選んで移動もできる）。
- 図が邪魔なときは畳める。スマホ・タブレットの体験リンクでも押せる大きさ。
