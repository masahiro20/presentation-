# 01 人が歩いているような動き（目線 170cm の人）

Status: done（2026-11-17。残りは Comments）

## 要望
今も移動・回転・目線はあるが、人が歩いて見えている目線に感じない。人が歩いているような動きで、周辺環境（屋外）と室内を見られるようにする。身長 170cm の人を想定。

## できあがり（確かめ方）
- 目の高さは身長 170cm の人（約 1.6m）。段差・階段では床に沿って上下する。
- 歩くと、歩幅に合わせた小さな上下・左右の揺れがあり、歩き出しと止まるときに加減速する（酔わない程度。切ることもできる）。
- 曲がるときは、視線が先に向いてから体が付いてくる（機械的な回転に見えない）。
- 壁・家具をすり抜けない。戸口は通れる。
- 屋外（道路側・アプローチ・庭）から玄関を通って室内へ、続けて歩ける。
- 打合せの画面と体験リンクの両方で動く。直す前と後を動画で見比べる。

  - 歩幅（0.7m）ごとに頭が約 2cm 上下・左右に約 1cm（`walkBob`。画面の「揺れ」で切れる）。止まると 1 秒以内に消える。
  - 体の向きは視線より 0.16 秒遅れて付いてくる（見回しながら歩くと、視線が先に向いてから進む向きが変わる）。←/→ は向きを変える（回り始め・止まりぎわをなめらかに）、A/D は横歩き。
