# 02 クリックで動くアクション（ドアを開ける など）

Status: ready-for-agent

## 要望
ドアを開けるなど、クリックしたら動くモーションがあるとリアル。

## できあがり（確かめ方）
- 歩いているときに開き戸・引戸・玄関ドアをクリックすると、動きつきで開閉し、開いた戸口を通れる。
- 候補（着手時に、効果の大きい順に決める）: 窓の開閉、ガレージのシャッター（クリックで巻き上げは済み。歩くモードからも）、照明の入切、カーテン・ロールスクリーン、収納の扉。
- クリックできる物は、カーソルを合わせると分かる（押せると気づける）。
- 体験リンクでお客様が触っても壊れない（元に戻せる）。
