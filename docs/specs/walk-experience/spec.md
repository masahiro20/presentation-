# 歩く体験（人が歩いて見ている目線・クリックで動く・広角・現在地の地図）

Status: ready-for-agent（2026-11-17 火 20:05 に開始を予約。それまで着手しない = ご利用枠の都合）

## 誰目線
- 使う人: 営業・設計士・コーディネーター（打合せで画面を動かして見せる）
- 見る人: お客様（打合せの画面で見る／体験リンクで自分でも歩く）
- → 使う人とお客様の両方の目線で、実際の動きを動画で確かめる。

## ご要望（2026-11-15）
- 質感・素材感・光の加減は良くなってきた。これはこれで OK。
- 次は歩く動き。移動・回転・目線はあるが、「人が歩いて見えている目線」に感じない。人が歩いているような動きで、周辺環境と室内を見られるようにしたい。
- 身長 170cm の人を想定する。
- ドアを開けるなど、クリックしたら動くアクションがあるとリアル。
- 通常の目線と、少し引いた広角の目線を切り替えたい（人は、画角で切り取るより広く見ている）。
- 室内に入ると見づらく、どこにいるか分かりづらい。右下などに平面図を出し、クリックするとその場所へ移動して、その目線で見られる地図がほしい。

## チケット
1. `issues/01-walk-motion.md` 人が歩いているような動き（目線 170cm の人）
2. `issues/02-click-actions.md` クリックで動くアクション（ドアを開ける など）
3. `issues/03-wide-view.md` 通常目線と「引きの広角目線」の切り替え
4. `issues/04-minimap.md` 現在地の地図（右下の平面図。クリックでその場所へ）

## 進め方
- 着手時に、今の歩くモード（3D の画面・体験リンク・ルームツアーの動画）の作りを確かめてから、チケットごとに作る。
- 仮に置いたこと（違えば直す）: 目の高さは身長 170cm の人で約 1.6m。打合せの画面と体験リンクの両方に入れる。
