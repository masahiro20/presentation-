## 見積の決め方で学んだこと
| 学んだこと | 根拠 | 反映 |
|---|---|---|
| S 仕様（金物工法）は**許容応力度計算**を入れる | S の 3 邸すべて（428,500 円。旧単価 285,700） | 済（S の既定） |
| S 仕様は**制振ダンパー evoltz**（＋施工 2 人工）を入れる | S の 3 邸すべて（542,800 円） | 済（S の既定） |

| 図面の面積表に**建築面積・施工床面積**があれば、その値で基礎・防蟻・坪数を数える | 大崎様: 図面 91.91／128.58 ＝ 積算。外形の重ね合わせでは 81.6 | 済（外れ値は使わない） |

| 鉄骨階段は 1 式 121.4 万円。蹴込みあり・長いものは × 1.2〜1.5 | 大崎様 1.2・位田様 1.5 | 未 |

  積算は屋根 155 ㎡・軒天 15 ㎡＋木板 74.4 ㎡・軒先 23 m。自動は軒の出 100mm の既定で屋根 88 ㎡（−43%）。
