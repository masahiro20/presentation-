# 03 部分的な仕様替えと立体感（折り上げ・折り下げ天井 ほか）

Status: needs-triage

## 要望
床だけ・壁だけ・天井だけ雰囲気を変える。折り下げ天井・折り上げ天井・スキップフロア・ダウンフロアなど、立体感のある仕様を入れられるようにする。

## いまできること（確認済みのもの）
- 床の段差（小上がり・ダウンリビング・スキップフロア・中二階）: 部屋ごとの床の高さ（`Room.floorOffset`）。
- 天井高を範囲で指定（方眼でドラッグ・3D で部屋をクリック）。LDK の天井だけ別の素材。
- 3D でクリックした床・壁の素材の切り替え。

## これから
- 折り上げ天井・折り下げ天井（範囲と段差、間接照明の有無）を、部屋の一部に入れられるようにする。
- 「この壁 1 面だけ」「この部屋の床だけ」の替え方を、パースの画面で迷わずできるようにそろえる（いまの操作を実際に使って、足りない所を洗い出す）。
- 見積・図面（天井伏せ・断面）への反映の要否を決める。
