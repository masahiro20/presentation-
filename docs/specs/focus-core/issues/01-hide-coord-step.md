# 01 「コーデ」のステップを外す（コードは残す）

Status: done（2026-11-17）

## やったこと
- `src/app/features.ts` の `FEATURES.coordStep = false`。ステップの並びは「図面読込 → パース → 図面 → 日照 → 見積 → 資料」。
- パースの画面の「コーディネートを開く」、読み込み結果の「コーデで見る」も一緒に外した。
- 残したもの: コーディネートのコード（`src/app/steps/coordStep.ts`・`src/coordinate/`）・テスト・保存した案件の中身（選んだ商品・決定の記録）。パースの画面で床・壁・天井などを替える操作。
- 戻し方: `FEATURES.coordStep` を true にする。

## 残り（御社に確認したい所）
- 体験リンクの「仕様を選ぶ」（お客様が候補から選ぶ）と、資料の仕様決定書のページは、コーディネートで候補を作ったときだけ出る作り。入口を外したので新しくは出ないが、同じ扱いで外してよいか。
- ほかに外す候補（使っていなければ）: 3D の写真仕上げ（AI）・動画の下絵・AR など。使っているものを教えてもらえれば、同じやり方で出し入れする。
