# 04 周辺環境をリアルに（目立つ建物・普通の家の屋根）

Status: needs-info（まず、今ある「Google 実写 3D」を御社のキーで試してもらう）

## 要望
中部電力 MIRAI TOWER・オアシス 21 のような建物を、大まかな形と高さではなく、もっと鮮明な景観として再現したい。普通の家も、ざっくりした屋根ではなくリアルに。

## いまある仕組み
- **Google 実写 3D**（`src/sun/googleEarth.ts`）: Google Earth と同じ写真測量の街並み（Photorealistic 3D Tiles）を、日照の周辺環境として敷ける。
  建物・樹木・地形が写真の見た目のまま出て、影も落とす。日照の画面の「Google の API キー」に、Map Tiles API を有効にしたキーを入れると使える（いまは未設定）。
  決まり: 表示と影にだけ使える（保存・書き出し・解析用の形への変換は Google の利用規約で不可）。Google の利用料がかかる。
- PLATEAU（国の 3D 都市モデル）: 整備済みの市では建物の形と高さ（屋根の形がある所は屋根も）。未整備の市は国土地理院の建物の外形に、推定の屋根。

## これから
- 御社のキーで、名古屋の中心部と、実際の敷地 2〜3 か所で Google 実写 3D を試す（見え方・重さ・料金の目安）。
- ほかの仕組みを調べる（PLATEAU の写真つきの建物モデルの取り込み、ほか）。X で見かけた仕組みがあれば、そのポストを教えてもらう。
