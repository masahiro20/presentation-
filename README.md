# 間取りプレゼン

**平面図の PDF だけ**から、立面図・外観／内観パース・ウォークスルー動画・日照シミュレーションまでを一気通貫で自動作成する、注文住宅の提案用 Web アプリです。ブラウザだけで動作し、サーバーは不要です。

```
平面図PDF ──▶ 図面解析 ──▶ 3Dモデル ──┬─▶ 外観・内観パース（テイスト選択／写真品質レンダリング）
                                      ├─▶ 立面図（東西南北・隠線処理済みベクター）
                                      ├─▶ 日照シミュレーション（航空写真・周辺建物・日影図）
                                      ├─▶ 動画（ウォークスルー／外観360°／日照タイムラプス）
                                      └─▶ プレゼン資料（全画面・PDF・HTML）
```

## 日照シミュレーション（3D データ読み込み版）

設計チームの **3DS データ（.3ds。OBJ / STL / GLB / FBX も可）だけ**から日照検討を行う独立した入口です（`sun.html`。Windows は `start-sun.bat`）。平面図 PDF は不要で、地図で指定した**実在の場所**に建物を**実寸**で置き、**地形の高低差と周辺建物を自動で立ち上げて**、季節・時刻ごとの日当たりと日影図を確認できます。

```
① 建設地（住所検索 or 地図クリック、任意で敷地の輪郭）
      └─ 自動取得: 地形（国土地理院 標高タイル 1m/5m/10m）・航空写真・周辺建物（PLATEAU 実測高さ → 国土地理院 推定高さ）・遠方の山による地平線
② 建物を置く（3DS を読み込み → 単位の自動判定と寸法の確認 → 真北からの向き → 正確な位置合わせ（2 点合わせ／敷地の輪郭に合わせる）→ 航空写真の上でドラッグ・数値入力 → 地盤に接地）
③ 日照シミュレーション（時刻・季節の再生、太陽の通り道、地面と建物の面の日照時間マップ、測定点の季節別日照時間、日影図、季節比較の撮影、タイムラプス動画、印刷用レポート）
```

**① 住所検索の精度** — 候補には「番地まで一致」「号まで一致」「丁目・町名まで」などの精度ラベルが付きます。国土地理院の住所検索で番地まで出ないときは、アドレス・ベース・レジストリ（デジタル庁）で番地・号の座標を引き直します。それでも出ない地域では、Google Cloud の Geocoding API キーを任意で貼ると Google の住所検索も使えます（キーはこのパソコンのブラウザにだけ保存され、サーバーには送りません）。住所のほかに「35.60193, 139.67363」のような緯度経度や、Google マップの URL（`@35.60,139.67,…` や `?q=…` を含むもの）を貼り付けてもピンを置けます。住所検索の下の「座標で指定（緯度・経度）」では、緯度・経度を 10 進（35.21058）でも度分秒（35°12′38.1″）でも直接入力してピンを置け（緯度と経度を取り違えても入れ替えます）、欄にはいつも今のピンの座標が表示されて「コピー」で「緯度, 経度」の形を書き写せます。番地まで特定できなかったときは、航空写真に切り替えてピンをドラッグして合わせてください。

**② 正確な位置合わせ** — 設計チームの 3DS を、航空写真と地図で描いた敷地の輪郭に対して「正確な向き・位置・寸法」で落とし込むための道具です。

| 操作 | 内容 |
| --- | --- |
| 📍 2 点合わせ | 真上からの視点で「建物の角 → 航空写真に写っているその角の実際の位置」を 2 組クリックします（軒先なら軒先どうし。角の近くをクリックすると自動で角に吸着し、航空写真をクリックする間は建物が半透明になります）。方位と位置が一度に決まり、残差（m）と**寸法の比**（航空写真上の距離 ÷ モデル上の距離）が表示されます。比が 1 から 3 % 以上ずれていれば単位（縮尺）を疑い、「寸法もこの比で合わせる」で縮尺ごと合わせられます。Esc で中止 |
| 敷地の輪郭に合わせる | 「建設地」で敷地の輪郭を描いてあるときに使えます。3DS に敷地（`site` / `lot` / `parcel` / `land` / `敷地` という名前のオブジェクト。オブジェクト一覧で非表示にしてあるもの — 読み込み時に自動で非表示になります）があれば、その板の外周（旗竿地・L 字の凹みも残します）を敷地の輪郭に重ねる向きと位置を自動で求めます（残差を表示。矩形の敷地で 180° の候補が同点なら今の向きに近い方）。3DS の敷地と描いた輪郭の大きさが 2 倍以上違うときは単位違いとみなして向きだけ合わせ、「寸法もこの比で合わせる」で縮尺ごと合わせ直せます。単位・上方向・反転・表示オブジェクトを変えると自動で合わせ直します。敷地オブジェクトが無ければ、建物の壁の外形の辺の向きを敷地の辺に合わせ、向きだけを直します（位置はそのまま） |
| 数値入力・微調整 | 「位置」の「東へ (m)」「北へ (m)」に数値を入力、0.1 / 0.5 / 2 m のボタン、「ピンの位置に戻す」。「方位（真北）」の ↺ / ↻ で 90° 回転 |
| キー操作 | 3D の上にポインタがあるとき — 矢印キー: 0.1 m（Shift で 1 m）移動、R / Shift+R: 時計回り／反時計回りに 90° 回転。Esc: 2 点合わせの中止（どこでも。2 点合わせ中は矢印キー・R は効かず、位置・向きのボタンや数値入力で配置を変えると 2 点合わせは中止されます） |
| 地図の足跡 | 「建設地」の地図には建物の外形を描きます。濃い線 = 壁、薄い面 = 軒先（航空写真で見えるのは軒先です）。周辺建物の除外にも軒先の外形を使います |

どう置いたか（2 点合わせ／敷地の輪郭／向きのみ／手動）と残差は、位置合わせの後に日照シミュレーションへ進むときの「配置の確認」ダイアログと、プロジェクト JSON に残ります。位置を合わせた（または手で動かした）建物は、ピンを動かしても地球上の同じ所に留まります（2 点合わせなら対応点から解き直し、それ以外は建物の基準点の緯度経度から戻します。測定点も建物と一緒に動きます）。読み込んだだけで動かしていない建物はピンに付いて動きます。

**③ 建物を選んで隠す** — 日照シミュレーションの「周辺建物の修正」→「🏠 建物を選んで隠す」で 3D の建物をクリック（もう一度で解除、Shift＋ドラッグで範囲選択。Esc で終了）し、操作バーで**隠し方**と**理由**を選んで「隠す」を押します。建物をクリックして開く案内（「非表示にする」）・建設地の地図の「地図で建物を選んで隠す」（輪郭をクリック。ピンは動きません）でも同じ隠し方・理由で隠せます（直近に選んだものが次の既定になります）。

| 隠し方 | 3D の表示 | 実時間の影 | 日照時間マップ・測定点・日影図 | 使いどころ |
| --- | --- | --- | --- | --- |
| 計算から除外 | 描かない | 落とさない | 含めない | 解体予定の既存建物・敷地内の既存建物・もう無いのに地図データに残っている建物・データの誤り |
| 表示だけ隠す（影・解析には残す） | 描かない | 落とす（色も深度も書かない「影だけのメッシュ」を影のマップに描く） | 含める | プレゼンで視点の手前にあってカメラの邪魔になる建物 |

- **理由**は「解体予定」「敷地内の既存建物」「データの誤り」「その他（自由記述）」から選び、隠し方と一緒にプロジェクト JSON に残ります。この機能より前に保存したプロジェクトの「隠した建物」は「計算から除外」「その他」として開きます。
- 「隠した建物（N 棟）」の一覧は隠し方ごと（計算から除外／表示だけ隠す）にまとめ、各行に方向・距離・高さ・理由を出します。行で隠し方・理由を直す・「戻す」、一覧の下の「すべて戻す」ができます。モード中は隠した建物を半透明で表示し（灰色 = 計算から除外、青 = 表示だけ隠す）、選んで「戻す」でも戻せます。建設地の地図では、計算から除外した輪郭は灰色の破線、表示だけ隠した輪郭は青の破線です。
- **印刷物への開示**（「勝手に建物を消した」と言われないように）: 日影図の SVG（画面・保存・レポート）の下には、いつも「周辺建物の扱い: 計算から除外した周辺建物 N 棟（解体予定 a・データの誤り b…）」（無ければ「なし」）と、別の行に「表示だけ隠した建物 N 棟（影・解析には含む）」、敷地・計画建物に重なって自動で外した建物の数を書きます（自建物のみの日影図では「この図は自建物のみで計算」と断ったうえで書きます）。レポートは日照の結果を載せるすべてのページ（季節比較・日照時間マップ・測定点・日影図）の下に同じ注記を付け、「周辺建物の扱い」のページに、計算から除外した建物と表示だけ隠した建物の表（建物・出典・高さ・理由・建物からの方向と距離）を載せます。前提チップと建設地のページにも棟数を明記します。
- 手動で追加した隣家も消さずに隠せます（消すのはポップアップの「削除」）。

**④ 想定の家（未建築の隣家）と敷地を細かく描く** — 分譲地などで隣の家がまだ建っていないときに、「建った想定」の家を置いて影・日照の検討に入れます。日照シミュレーションの「周辺建物の修正」→「想定の家（未建築の隣家）」で操作します。

| 操作 | 内容 |
| --- | --- |
| 置く | 「置く形」で平屋（切妻）・2 階建て（切妻／片流れ／寄棟）・3 階建て（陸屋根）・アパート 2 階（陸屋根）・箱（高さだけ）を選び、「＋ 想定の家を置く」（ボタンが黒くなり十字カーソル）→ 3D の地面（航空写真）をクリック。続けて何棟でも置け、Esc かもう一度押すと終わります（回転のドラッグでは置きません）。向きは敷地の輪郭の主な辺（輪郭が無ければ計画の建物）にそろえ、棟（長手）は東西に近い向きにします。既存の家の屋根をクリックするとその真下に置きます（取り壊す家は「建物を選んで隠す」で計算から除外してください）。「計画の建物と同じ形を置く」は計画の建物の幅×奥行×高さの箱を同じ向きで置きます |
| 直す | 3D で想定の家をクリックすると編集欄（名前・形・幅・奥行・向き・屋根・軒高・最高高さ・勾配（寸）、↺／↻ 90°・複製・削除）が開きます。数値は確定（Enter・欄の外へ）で反映。寸法と高さは自由に入力でき（プリセットは初期値）、「勾配 寸」を入れると最高高さを計算します（切妻・寄棟は奥行の半分、片流れは奥行＋軒の出が水平距離。最高高さを直すと勾配の表示が変わります）。想定の家はドラッグで水平に動かせ、選んでいる間は R／Shift+R で 90° 回転、矢印キーで 0.1 m（Shift で 1 m）移動、Delete で削除、Esc で閉じます。「複製」は棟の向きに 幅 + 2 m ずらした同じ家（分譲地の並び）。一覧（名前・寸法・高さ・屋根・建物からの方向と距離）の「編集」「削除」でも直せます |
| 含める | 「想定の建物を含める（影・解析）」を外すと、3D に描かず、影・日照時間マップ・測定点・日影図からも外します（一覧とプロジェクト JSON には残り、入れ直すと戻ります） |
| 建設地の地図 | 地図の上でも想定の家を置けます: クリックで置く、敷地の辺をクリックするとその辺の向こうの隣の区画（分譲地の次の区画）に置く、区画を描いてその中に置く。区画に置くときは隣地・道路からの離れと建ぺい率を見て区画の中に収めます |

- 形は屋根付き（切妻・寄棟・片流れ・陸屋根）で、軒の出 0.45 m も影を落とします。色は薄い青の壁・青灰の屋根で、実在の建物と見分けられます。「建物を選んで隠す」・測定点を置くモードとは同時に使いません（どれかに入ると他は終わります）。
- 置く・動かす・直す・消す・含める／含めないのたびに、古い解析結果（日照時間マップ・日影図・測定点の結果・比較画像）は消えます。
- **開示**: 日影図の脚注・レポートの日照の各ページと建設地の表に「想定で置いた建物 N 棟（未建築・仮の形状。影・解析に含む）」（含めていなければ「今は含めていません」）、前提チップに「（うち想定の家 N）」と書きます。
- **敷地を細かく描く**: 建設地の地図はズーム 22 まで拡大できます（地理院タイルの配信はズーム 18 までなので、その先はタイルを引き伸ばして表示）。描いている輪郭の各辺に長さ（m）を表示し、辺の長さを数値で入力して直せます。「寸法で区画を作る」で間口・奥行の寸法から区画を作れます。辺の中点から頂点を足し、頂点を選んで Delete で消し、元に戻す（undo）もできます。Shift を押しながら置く・動かすと角度を吸着してそろえます。

| 項目 | 方法・出典 |
| --- | --- |
| 太陽位置 | NOAA の計算式（大気差補正込み、±0.01°）。時刻は日本標準時（JST）、方位は真北基準 |
| 地形 | 国土地理院 標高タイル（DEM1A 1m → DEM5A/5B/5C 5m → DEM10B 10m の順に利用可能なもの）。建物の足元・周辺建物の足元を地形に接地。半径 10km の粗い DEM から山・丘による地平線も計算 |
| 周辺建物 | PLATEAU（国土交通省 3D 都市モデル、東京23区・実測の高さ）があればそれを、無い建物は国土地理院の建物種類から推定（普通建物 約7m・堅ろう 12m・高層 30m・無壁舎 2.8m）。推定の建物は色で区別し、クリックして高さを修正できます |
| 縮尺 | 3DS の寸法から mm / cm / m を自動判定し、幅×奥行×高さを表示。実寸の幅を入力して合わせることも、2 点合わせの寸法の比から合わせることも可能。地面・敷地の板などの余計なオブジェクトは自動で除外（一覧で変更可） |
| 外形 | 建物の外形は、焼き込んだ三角形を底面から 0.3〜2 m の水平面で切った断面の凸包（壁）と、全高さの凸包（軒先）の 2 つを使い分けます。3DS の敷地オブジェクトは板の天面の境界辺をつないだ外周（凹みも残る。取れない形は凸包）です（`src/sunstudy/alignment.ts`）。位置合わせの計算（2 点対応・最小二乗・凸包・外形どうしの ICP）は `src/sun/align.ts` |
| 解析 | BVH レイキャスト（地形・周辺建物（表示だけ隠した建物を含み、計算から除外した建物は含まない）・自建物）。日影図は冬至日（その年の実際の日: 年により 12/21 か 12/22）・真太陽時 8〜16 時（北海道 9〜15 時）、測定面は建物足元の平均地盤面 +1.5 / 4 / 6.5m。「規制値」で別表第 4 のプリセット（一般（一）（二）（三）・北海道（一）（二）（三）。北海道は真太陽時 9〜15 時に切り替え）を選ぶと、その 2 本（5〜10m の規制 X 時間・10m 超の規制 Y 時間）の等時間日影線を太く描きます（線を描くだけで、規制への適否は判定しません。「なし」は参考の 2〜5 時間）。「時刻日影線を 30 分ごと」で 30 分の線（破線。ラベルは正時）も描きます。図の範囲は建物の最高高さの影が時間帯の各時刻に届く所まで（最大で中心から 400m。格子は 400 万セル以内）。等時間日影線は日向⇄日陰の遷移時刻を二分法で求めて積算、時刻日影線は格子の辺の上で位置を二分法で求める。5m/10m ラインは敷地境界から水平距離 5m・10m の線（凸の角は半径 5m・10m の円弧、凹の角・狭い切り込みは交点でつなぐ。敷地の輪郭を描いたときだけ表示）。配置・周辺環境が変わると古い結果（日照時間マップ・日影図・測定点の結果・比較画像）は自動で消えます |
| 保存 | プロジェクト JSON（3D データと取得済みの周辺環境・位置合わせの記録を同梱。オフラインでも開けます） |

※ 本ツールの日影図は検討用であり、建築確認申請用の日影図ではありません。

## 使い方

### Windows でかんたんに起動
1. [Node.js](https://nodejs.org)（LTS 版）をインストール
2. [ZIP をダウンロード](https://github.com/masahiro20/presentation-/archive/refs/heads/claude/madori-presentation-tool.zip)して展開（右クリック →「すべて展開」）
3. 展開したフォルダの `start.bat` をダブルクリック（初回のみ数分かけて準備）→ ブラウザが開きます

### コマンドで起動

```bash
npm install
npm run dev        # http://localhost:5173 を開く（3D データ読み込み版の日照は /sun.html）
npm run build      # dist/ に静的サイトを出力（任意の Web サーバーに置くだけで動きます）
npm test           # テスト（図面解析・地図・地形・3D 読み込み・位置合わせ・日照解析）
```

1. **図面読込** — 平面図 PDF をドロップ（「サンプル平面図」ボタンですぐ試せます）。認識した部屋名・用途・方位・床高/階高/天井高はその場で修正できます。
2. **外観・内観パース** — 3D は「回転」「✋移動（画面を掴んで横移動）」の切替、右ドラッグ／スペースキーでも移動、ホイールでカーソルの位置へズーム。外観7種・内観6種の「テイスト」カードを選ぶだけで、外壁・屋根・サッシ・床・壁・家具・外構まで一式切り替わります。屋根形状・外壁色・時間帯（昼/夕景/夜景）も個別に変更可能。見どころカメラは自動生成され、「写真品質でレンダリング」で GPU パストレーシングによるフォトリアルな画像を書き出せます。
3. **立面図** — 3D モデルから東西南北4面の立面図（カラー/線画）を自動作成。GL・各階FL・軒高・最高高さを記入。SVG/PNG 保存。
4. **日照シミュレーション** — 住所検索で建設地を設定すると、国土地理院の航空写真と周辺建物を読み込み、Google Earth のような感覚で季節・時刻ごとの日差しと影を確認できます。建設地は「座標で指定（緯度・経度）」で緯度・経度（10 進・度分秒）を直接入力することもでき、今の建設地の座標をコピーできます。設計の 3DS を読み込んで正確な建物で影を計算し、建物の角と航空写真の 2 点合わせで位置・向きを合わせることもできます。
5. **動画** — ウォークスルー（道路→玄関→各部屋、部屋名字幕付き）、外観360°、日照タイムラプス（冬至/夏至）を MP4 で書き出し。
6. **プレゼン資料** — 「足りない素材を自動作成」を押すだけで、表紙・コンセプト・間取り・パース・立面図・日当たり・部屋一覧をまとめたお客様向け資料が完成。全画面プレゼン、PDF 印刷（A4横）、HTML 書き出しに対応。

## 標準仕様とテイスト（ホームランディック標準）

パースの「洗練された雰囲気」は仕上げの色だけでなく、建具・窓・照明の**納まり（線の少なさ）**で決まります。そのため、テイストとは別に「標準仕様」を持ち、既定をホームランディック標準にしています（`src/styles/spec.ts`）。

| 項目 | ホームランディック標準 | 一般的な仕様（比較用） |
| --- | --- | --- |
| 室内ドア | KAMIYA フルハイトドア（天井まで・上枠/下がり壁なし・ステルス枠・扉厚40mm・細身レバー） | H2000 の扉＋三方枠＋下がり壁 |
| 窓 | サッシ上端＝天井高（窓上の壁の線をなくす）、室内側は塗り回し（額縁・窓台なし） | 窓ごとに高さが異なる、額縁・窓台 |
| カーテン | 天井埋込のカーテンボックス（レールを見せない） | レール露出 |
| 照明 | ダウンライト＋天井際の間接照明 | シーリングライト |

「納まりを細かく調整」で、フルハイトドア・サッシ高さ・間接照明・カーテン・室内ドアの色・天井高を案件ごとに変更できます。

テイストは、外観が **塗り壁（ホワイト／グレージュ／ライトグレー／チャコール）**、内観が **ホテルライク・グレージュ／ペールベージュ／ライトグレー／グレージュ×ウォールナット** を標準にしています（一般的なテイストは「その他（比較用）」に格納）。

## 提案用パースは写真品質で出力

- 画面上の操作（回転・移動・テイスト切替・ウォークスルーのプレビュー）は動きを優先したリアルタイム表示です。
- **提案用に保存するパースはすべて写真品質**（GPU パストレーシング：間接光・柔らかな影・ガラスの映り込み、ノイズ除去、写真的なトーン仕上げ、室内は室内に合わせた露出）で書き出します。フルHD〜4K。
- プレゼン資料の自動作成も写真品質でレンダリングします。確認用の「下書き」を使った場合は、資料に「下書き」の印が付きます。

### 2. 3D 生成（`src/scene/`, `src/styles/`）
- 壁は開口部で分割し、外壁・内壁・浴室などで仕上げを自動で塗り分け。サッシ（引違い・召し合わせ）、建具（開いた扉・引戸）、カーテン、基礎、水切り、ポーチ、庇、階段（直・折り返し）
- **屋根の自動生成**: 外形を極大矩形で被覆して切妻・寄棟・片流れ・陸屋根（パラペット）をかけ、L字では屋根同士が交差して谷ができます。上階が載らない部分には下屋を自動でかけます
- **手続き的 PBR テクスチャ**: サイディング・塗り壁・ガルバリウム・杉板・レンガ・スレート・瓦・フローリング・ヘリンボーン・大理石・畳など（画像素材不要・ライセンスフリー）
- **家具の自動配置**: LDK はキッチン（洗面室に近い側）→ダイニング→リビングにゾーニング。寝室はベッドを窓の少ない壁へ。水回りの設備、植栽も配置
- **見どころカメラ**: 外観は縦線補正（レンズシフト）の2点透視で南面が見える角度を優先。内観は部屋内の候補位置からレイキャストで見通し・窓の見え方・扉や家具との干渉を評価して選定
- **写真品質**: three-gpu-pathtracer による大域照明・柔らかい影・映り込みのパストレーシング＋ノイズ除去

### 3. 日照シミュレーション（`src/sun/`）
- 太陽位置は NOAA の計算式（大気差補正込み）。真太陽時・日の出/南中/日の入も計算
- 国土地理院の**航空写真タイル**、**住所検索**、**ベクトルタイルの建物外形**（全国）を利用。OpenStreetMap（高さ・階数タグ）にも対応。周辺建物の屋上には航空写真を貼り付け。建設地は住所検索のほか「座標で指定（緯度・経度）」で 10 進・度分秒の座標を直接入力でき（緯度欄に「緯度, 経度」の 1 行や Google マップの URL の貼り付けも可。緯度と経度が逆なら入れ替えて案内）、今のピンの座標を度分秒でも確認し「緯度, 経度」の形でコピーできます
- 3D 上に**太陽の通り道**（冬至・春秋分・夏至、時刻目盛り）と方位を表示。日付チップと時刻スライダー、再生（タイムラプス）
- **部屋ごとの日当たり解析**: 床面のサンプル点から太陽方向へ BVH レイキャストし、時刻ごとの日射率・日照時間・日が入る時間帯を算出 → 「冬至でもLDKに 9:10〜14:40 陽が差し込みます」のような説明文を自動作成
- **日照時間マップ**: 敷地まわりの地面の日照時間をヒートマップ表示
- **日影図**: 冬至日（その年の実際の日）・真太陽時 8〜16 時、測定面 GL+1.5m/4m の時刻日影線と等時間日影線（2〜5時間）、敷地境界から水平距離 5m/10m のライン（角は円弧）。図の範囲は建物（3DS で置き換え中は 3DS）の高さと冬の低い太陽の影が届く所まで広げます。日影図のボタンの下の「日影図の規制値」で 別表第 4 の規制時間（一般（一）〜（三）・北海道（一）〜（三）。北海道は真太陽時 9〜15 時）を選ぶと、5〜10m・10m 超の規制時間の等時間日影線を太く描きます（線を描くだけで適否の判定はしません。既定は「なし（参考の 2〜5 時間）」）。「時刻日影線を 30 分ごと」で 30 分刻み（破線、ラベルは正時）にもできます。この版の日影図は計画建物だけの影で、図の下に「周辺建物は日影図に含めていません」と、部屋の日当たり・日照時間マップでの周辺建物の扱い（計算から除外した建物の理由ごとの棟数・表示だけ隠した建物の棟数）を印字します
- **設計の 3D データで正確な建物にする**（日照ステップのパネル）: 設計チームの 3DS（OBJ/STL/GLB/FBX も可。3D 画面へのドロップでも可）を読み込むと、図面から起こした建物の代わりに正確な形で影を落とします。読み込むと 1 階外形の壁の断面を PDF の外形に自動で合わせ（PDF に無いポーチ・下屋は無視して主屋の壁で合わせる）、「PDF 外形 W×D／3DS W×D」と残差を表示。単位（mm/cm/m…）・左右反転・1 階の床の高さ・図面の上下左右 0.1/0.5 m の微調整・↺↻ 90°/1°（3D の上で R / Shift+R）・「間取りに自動で合わせる」「自動配置に戻す」「3DS を外す」。「3DS で影を計算する」が ON のとき、実時間の影・日影図・地面の日照時間マップは 3DS で計算し、部屋ごとの日当たりは PDF の部屋を使って 3DS の床のすぐ上から判定（ガラスはマテリアルから判定して光を通す。窓の開口が無い 3DS では 0 時間になるので案内を出す）。3DS はこのステップの表示中だけ使われ、別の PDF を読み込むと自動で外れます（保存は未対応。ページを再読み込みすると再読み込みが必要）
- **2 点合わせ（建物の角 → 航空写真の同じ角）**: 建設地のパネルで、建物の角 → 航空写真上のその角の実際の位置、を 2 組クリックすると、位置（敷地のずれ）と真北の向きを同時に解きます（2 点は 0.5 m 以上離す。配置や位置・向きを変えると途中の 2 点合わせは中止。Esc でも中止）。日照シミュレーション（3D データ読み込み版）と同じ色・手順です
- **周辺建物を選んで隠す／高さを直す**（周辺環境のセクション）: 「🏠 建物を選んで隠す」で、3D の建物をクリック（もう一度で解除）・Shift+ドラッグの範囲選択（建物の中心が入るもの）で選び（選んだ建物はオレンジ）、画面上のバーで隠し方と理由を選んで「隠す」で外します。隠し方は 2 通り:
  - **計算から除外**（既定）: 解体予定の既存建物・もう無い建物・データの誤りなど。3D に出さず、影も落とさず、部屋ごとの日当たり・日照時間マップにも入りません
  - **表示だけ隠す（影・解析には残す）**: プレゼンで視点を遮る建物など。3D には描きませんが、影だけのメッシュ（色も奥行きも書かない・影は落とす・自分は影を受けない）で実時間の影を落とし、部屋ごとの日当たり・日照時間マップの遮蔽物にも残ります
  - 理由は 解体予定／敷地内の既存建物／データの誤り／その他（自由記述）から選び、隠し方と一緒に記録します（最後に選んだものを覚える。以前の記録など隠し方・理由の無いものは「計算から除外・その他」として読みます）
  - モード中は隠した建物を薄く（輪郭付き。計算から除外は灰色・表示だけ隠すは青）表示し、選んで「戻す」で戻せます（Esc・「終了」で終わる。敷地をクリック・2 点合わせとは同時に効かない）。サイドの「隠した建物（N 棟）」は隠し方ごとにまとめて理由を添え、1 棟ずつ「戻す」・隠し方の切り替え（「表示だけにする」「除外にする」）・「すべて戻す」ができます（行に重ねると 3D に薄く表示）。ふだんは建物をクリックすると、出典・方角と距離・建築面積の案内が開き、高さ (m) を直す・隠し方と理由を選んで「この建物を隠す」、ができます
  - 隠した建物・隠し方と理由・直した高さは、建物のキー（出典 + 重心 0.5 m 単位 + 面積 1 m² 単位。重心は取得地点によらない座標）と外形で記録し、周辺建物を取り直しても（建設地の微調整の後・国土地理院 ⇄ OSM）同じ建物に当て直します。「周辺建物をすべて消す」で記録も消えます（`src/sun/context.ts`）
  - **注記（恣意的に外したと言われないように）**: 部屋の日当たり・日照時間マップの結果の下、日影図の SVG／PNG、プレゼン資料の日照のページすべてに、影に含めた周辺建物の棟数、計算から除外した建物の理由ごとの棟数（「計算から除外した周辺建物 2 棟（解体予定 1・その他 1）」、無ければ「なし」）と、別に「表示だけ隠した建物 N 棟（影・解析には含む）」を印字します。資料には「計算から除外した周辺建物」の表（No.・出典・高さ・理由・方向・距離）のページも入ります。数字は結果を作った時点の扱いです（`src/app/sunDisclosure.ts`）
- **想定の家（未建築の隣家）**（周辺環境のセクションの青い枠）: 分譲地などで隣の家がまだ建っていないとき、「建った想定」の家を屋根付きで置いて影・日当たりを確かめます。形はプリセット（平屋（切妻）・2 階建て（切妻／片流れ／寄棟）・3 階建て（陸屋根）・アパート 2 階・箱（高さだけ））から選びます（形と区画の計算は `src/sun/plannedHouse.ts`）
  - 「＋ 想定の家を置く」: 航空写真（読めなければ地面）の上をクリックした所に、計画の建物と平行に（棟を PDF の建物の長手に合わせる。真北の角度も反映）置きます。続けて置け、もう一度押す・Esc で終わります（ドラッグは視点の操作で、置きません）
  - 「敷地の隣に想定の家」: 図面の敷地と同じ大きさの区画を、選んだ側（北側（裏）・東側（右隣）など。既定は道路ではない側）に並べ、それぞれに家を置きます（隣地側 1 m・道路側 2 m 離し建ぺい率 50% 以内、余裕があれば北に寄せる）。道路の側を選ぶと道路の幅（図面の幅員、無ければ 6 m）だけ離した向かいの区画に置きます。区画は青の破線で表示し、もう一度押すと同じ側は置き直します
  - 置いた家をクリックすると編集の案内（名前・形・幅・奥行・向き・屋根・軒高・最高高さ・勾配（寸）・↻ 90°・複製・削除）が開き、選んだ家（オレンジ）はドラッグで地面の上を移動（3 px 動かすまではクリック）、R / Shift+R で 90° 回転、Delete で削除できます。サイドの「置いた想定の家（N 棟）」から 編集・削除・すべて消す
  - 「想定の建物を含める（影・解析）」を外すと、想定の家は 3D・影・部屋の日当たり・日照時間マップから外れます（一覧には残る）。置いた家の棟数と扱いは「想定で置いた建物 N 棟（未建築・仮の形状。影・解析に含む／今は含めていません）」として結果の注記・日影図・プレゼン資料の日照のページと収録内容に印字します
  - 想定の家を置く・敷地をクリック・2 点合わせ・建物を選んで隠すは同時に効きません（どれかを始めると他は終わる）
- 位置・向き・3DS・周辺建物（隠す・戻す・高さの修正・想定の家を含む）を変えると、計算済みの部屋の日当たり・日影図・日照時間マップ・季節比較の写真は破棄し、プレゼン資料の作成時に作り直します（資料には「日当たりは設計 3D データ（3DS）で解析」の注記が入ります）

ハウスメーカー各社の提案でよく用いられる「季節（冬至・夏至）比較」「時刻アニメーション」「室内への日の入り方」「日影図」「周辺建物を考慮した日当たり」「軒・庇による夏冬の日射コントロールの説明」を取り込んでいます。

### 4. 動画（`src/video/`）
- 部屋のつながり（ドア）からグラフを作り、玄関→LDK→和室→階段→2階の各部屋を巡るルートを自動作成。視線は先読みで滑らかに、玄関・階段は暗転で切り替え
- 1コマずつ高画質でレンダリングし、WebCodecs（H.264）＋ mp4-muxer で MP4 に。未対応ブラウザは WebM

## 対応状況・注意点
- **CAD から出力したベクター PDF** が最も高精度です（ARCHITREND のカラー平面図・白黒平面図など）。
- **手描き風の平面図**（Illustrator の手描きブラシ等、線が揺れている図面）は、太線を画像化して壁の帯を検出する方式で読み取ります。
- **スキャン画像の PDF** は、ページを画像にして太い線（壁）を取り出し、壁の芯が 910mm モジュールにそろう性質と壁の厚みから縮尺を推定します。文字（室名）は読み取れないため、部屋名・用途は一覧で指定してください。見出しの読めないスキャンが複数ページある場合は別案とみなし、1ページ目を使います。
- 図面に**面積表**（「1階 100.20」）があれば各階の床面積と照合し、室名の無い中庭・ポーチ・建物間の通路などを屋外として判定します。
- 解析精度は図面の描き方に依存します。**実際にお使いの CAD の PDF でテストし、調整していくのが次のステップ**です（`samples/generate_sample_plans.py` のテスト図面では壁・部屋・開口部・階段・方位をすべて認識）。
- 周辺建物の高さは、国土地理院データでは建物の種類からの推定（普通建物 約7m）です。正確な高さが必要な場合は手動で隣家を追加してください。
- 写真品質レンダリング・動画書き出しは GPU 性能に依存します（一般的なノート PC で数十秒〜数分）。

- バルコニー・吹抜・ロフト・出窓・造作家具への対応、窓サイズの読み取り（建具表・記号）
- PLATEAU（3D 都市モデル）による周辺建物の正確な高さ、天空率
- 生成パースを下絵にした AI 仕上げ（画像生成）による質感アップ、360°パノラマ・VR
- スキャン図面の文字認識（OCR）による室名の読み取り
