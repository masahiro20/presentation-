# 01 周辺に建物が少なく見える（リアリティ）

Status: ready-for-agent

## 要望
周辺の立ち上げ自体は悪くないが、リアリティが足りない。建物があまり建っていない印象。

## できあがり（確かめ方）
- 着手時に、実際の住所 3〜5 か所（市街地・郊外の分譲地・田畑の多い所）で立ち上げ、「地図では建っているのに出ていない建物」を数えて原因を分ける
  （建物データが無い地域／読み込む範囲が狭い／取り込みに失敗している／出ているが淡くて見えない）。
- 原因ごとに直し、同じ場所で直す前と後を画像で見比べる。住宅地なら、敷地のまわりが家で埋まって見える。
- 影の計算に入る建物と、見た目だけの建物の区別は崩さない（日照の結果が変わるときは、そのことを画面に出す）。
