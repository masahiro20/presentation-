# 海外の住宅プレゼンツールから学ぶ（2026-11-25）

ご依頼: 「海外は 3D にしたときの洗練された美しさ・クリエイティブさ・自由度が良い。機能を一通り洗って、生かせる部分を導入する」。
目線: 使う人（設計士・営業）は速く迷わず、見る人（お客様）は一目で分かってワクワクする。

## 今回入れたもの: 3D 間取り図

- パースの構図に「N階 3D間取り図」を階ごとに追加（構図の札は「間取図」）。
  - 真上に近い角度（62°）・狭い画角（24°）で遠近の歪みを少なく、壁の向き（道路側に最も近い軸）にそろえる。
  - 敷地・庭・塀・木・隣家・空・霞を消し、明るい無地の台の上に輪切りの階だけを置く（影は柔らかく台に落ちる）。
  - 壁の切り口（天端）を濃い色で締める。部屋名の札は図面の文字のように小さく、設計士のメモ（社内向け）の札は出さない。
  - 下の階の屋根（下屋）は残す（消すと、上の階より張り出した下の階の部屋が上から透けて見えた。お客様の図面 11 邸で確認）。
  - ほかの構図・輪切りの解除・街並みの切り替えで元の見せ方に戻る（`Viewer.setPlanLook`）。
- 提案資料: 「足りない素材を自動作成」で 3D 間取り図の下絵も撮り、各階の間取りのページの次に 1 枚載せる。
- カット集の ZIP にも入る（外部で写真に仕上げられる）。

## 入れたもの 2: 360° ビュー（2026-11-25）

- パース →「仕上げ」→「360° ビュー」: 部屋ごと（LDK・玄関・ホール・個室・洗面）に、目線 1.4m から見回す 360° 画像を作る。
  - 立つ位置は、背の高い家具から 45cm 以上・壁から 45cm 以上離れた、なるべく部屋の中央（名札の位置はキッチンの島の上になることがあった）。
  - 正面（画像の中央）は、その部屋の内観パースの向き。
  - 立方体の 6 面を通常の高品質の描画（陰影・トーン）で撮り、正距円筒（4096×2048）に貼り直す（`scene/panorama.ts`）。
- その場で見回せるプレビュー（ドラッグ・ホイール）と、ZIP 保存。JPEG に 360° 写真の印（GPano）を入れ、Google フォト・Windows のフォトで見回せる。
- 「いまの位置で 360°」: 目線モードで立っている位置から 1 枚。

## 次の候補（効果の大きい順）

1. 平面図の読み取りを 100% に近づける（ご指示: まず平面図を正しく起こす → その次に 3D への変換）。
2. 3D 間取り図の質感: 壁の天端を濃い色で締める（海外の 3D 間取り図の読みやすさ）・床の素材ごとの色分けを強める。
3. 外観の「3D の線画」（Higharc のパンフレットの正面図）: 白模型の線を資料用に。
